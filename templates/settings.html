Telegram-уведомления

При изменении страницы RivalWatch может прислать сообщение.

Подключение

  1. Создай собственного бота в Telegram через @BotFather.
  2. Скопируй .env.example в .env и добавь туда TELEGRAM_BOT_TOKEN. Никогда не публикуй этот файл.
  3. Напиши боту /start, затем выполни python telegram_chat_id.py, чтобы узнать Chat ID.
  4. Введи Chat ID ниже и перезапусти worker.

Если Chat ID пустой, уведомления отключены.
