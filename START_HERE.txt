RivalWatch — учебный проект для GitHub

1. Установи Python 3.11+.
2. Запусти install.bat.
3. Запусти start_web.bat и открой http://127.0.0.1:5000
4. Зарегистрируйся и добавь демостраницу.
5. Проверь её, измени цену в demo.html, проверь ещё раз.
6. Для автоматической проверки запусти start_worker.bat.
7. Telegram — по инструкции README.md.

Сервис только для локального запуска, не размещай его публично без доработок безопасности.
